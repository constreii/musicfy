Untuk login ke YouTube Music (sync playlist asli), ikuti cara ini:

# 1. Install ytmusicapi
pip install ytmusicapi
# 2. Login via OAuth
ytmusicapi oauth
# 3. Ikuti instruksi di browser
# 4. File oauth.json akan tersimpan
# 5. Taruh di folder backend/
# 6. Restart backend

ℹ️ Info: Tanpa login, semua fitur tetap jalan normal. Login hanya untuk akses akun YT Music kamu.
